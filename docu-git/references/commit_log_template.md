# Docu-Git 커밋 로그 템플릿 (Commit Log Template)

`DOCU_HISTORY.md` 및 프로젝트 별 이력 파일 기록 시 사용하는 규격 템플릿입니다.

---

## 1. 개별 커밋 항목 템플릿 (Commit Entry Template)

```markdown
## [Commit: doc-commit-{YYYYMMDD}-{HHMMSS}] - v{버전} ({타임스탬프})
- **파일명**: `{문서명}_v{버전}_{주요변경사항}.{ext}`
- **작성자 / 에이전트**: Docu-Git Agent (Pairing with User)
- **작업 유형**: `[NEW / UPDATE / REFACTOR / REVISION / ROLLBACK]`

### 📥 사용자 요청 요약 (Input Summary)
> **의도**: {사용자 요청의 핵심 목적}
- **주요 지시사항**:
  - {지시사항 1}
  - {지시사항 2}

### 📤 산출물 요약 (Output Summary)
> **핵심 요지**: {산출물의 주요 결론 및 핵심 논지}
- **구조적 변화**:
  - {변화 1}
  - {변화 2}
- **추가/수정된 주요 내용**:
  - {핵심 내용 1}
  - {핵심 내용 2}

### 🔍 변경 내역 (Diff Snapshot)
- **추가/강조**: {새로 도입된 개념, 이론, 데이터}
- **제거/대체**: {삭제되거나 변경 이전 논리}
- **연관 문서/참고 자원**: `{이전버전_파일명}` -> `{현재버전_파일명}`

---
```

---

## 2. 전체 이력 매니페스트 헤더 템플릿 (Manifest Header)

```markdown
# 📜 Docu-Git 문서 변경 이력 (DOCU_HISTORY.md)

| 문서명 | 프로젝트 | 현재 버전 | 최근 업데이트 | 커밋 수 |
| :--- | :--- | :---: | :---: | :---: |
| {프로젝트 문서명} | {프로젝트명} | `v{최신버전}` | {YYYY-MM-DD HH:mm} | {N}개 |

---

## 📌 버전 이력 타임라인 (Timeline)

- `v0.1` ({날짜}): 최초 개요 작성
- `v0.5` ({날짜}): 이론적 틀 확립 (젠의 역량접근법 단일화)
- `v1.0` ({날짜}): 최종 완성본

---
```
