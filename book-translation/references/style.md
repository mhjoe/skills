# 번역 원칙

## 1. 완역

- 요약·축약·발췌본을 만들지 않는다. 원문의 모든 문단, 모든 대화, 모든 묘사가 대응하는 한국어를 갖는다.
- "이하 유사한 묘사가 이어진다", "(중략)" 같은 표시는 실패 신호다.
- 원문 문단 구분을 유지한다. 두 문단을 하나로 합치지 않는다. `verify.py`가 문단 수를 대조한다.
- 목록·표·시(詩)는 원문의 행 구분을 그대로 살린다.

## 2. 문체

- 화자의 시제와 인칭을 원문대로 따라간다. 현재형으로 쓰인 소설을 과거형으로 옮기지 않는다 — 「크리스마스의 만남」은 현재형이 결말의 시간 착란을 지탱한다.
- 화자의 격(格)을 고정한다. 1인칭 회고체·서간체·일지체는 각각 다른 종결어미 체계를 갖는다.
- 대화는 인물의 계급·나이·시대를 반영하되, 지나친 사투리 치환은 하지 않는다. 19세기 영국 하인의 말투를 한국 사투리로 옮기면 배경이 무너진다. 존대·하대의 층위로 계급을 표현한다.
- 긴 만연체를 짧게 끊어 "읽기 쉽게" 만들지 않는다. 문장 길이도 원문의 정보다.

## 3. 강조와 인용

| 원문 | 번역본 표기 |
| :--- | :--- |
| 이탤릭 강조 | `**굵게**` |
| 편지·엽서·전보·신문 기사·일기·유서 등 작중 문서 | `>` 인용 블록 |
| 서사적으로 결정적인 한 문장 | `**굵게**` |
| 장면 전환 공백 | `---` 또는 빈 줄 하나 (원문 조판을 따른다) |

작중 문서를 인용 블록으로 뽑아내면 결말의 무게가 달라진다. 「크리스마스의 만남」의 출판사 주석, 「해리」의 신문 기사가 그 예다.

## 4. 인물 이름

- 첫 등장 시 `한국어 (원어)` 병기. 이후로는 한국어만.
- 외래어 표기법을 따르되 관용 표기가 굳어진 이름은 관용을 따른다.
- 화자가 이름 없이 "나"로만 등장하면 등장인물 블록에 `**화자**`로 적는다.

## 5. 역주

`*[역주] …*` 형식으로 **본문 안에** 삽입한다. 각주 모음을 파일 끝에 만들지 않는다 — 독자가 그 자리에서 알아야 결말이 성립하는 경우에만 붙이기 때문이다.

### 붙이는 경우
번역으로 **소실되는** 것에만 붙인다.
- **언어유희가 플롯을 지탱할 때** — 「W. S.」의 *come to grips* / *handshake* / *sent to Coventry*. 마지막 교살 장면 전체가 이 말장난에 걸려 있어 역주 없이는 결말이 성립하지 않는다.
- **제목의 다의성** — 「Ringing the Changes」의 삼중 의미(전종술·되풀이·바꿔치기)
- **한국어에 대응어가 없는 문화·전승·직업 용어** — 노르웨이 선박 용어 seksring/fembøring, 드라우그 전승
- **인용의 출처** — 셰익스피어 「십이야」 인용 등, 원문 독자는 알아채고 한국 독자는 못 알아채는 것
- **라틴어·프랑스어 등 원문에서도 외국어인 대목** — *lucus a non lucendo*

### 붙이지 않는 경우
- 본문을 읽으면 알 수 있는 내용의 부연
- 작품 해석 — 그건 `## 🔍 심층 해설`의 몫이다
- 단순한 지명·화폐 단위(문맥으로 통하면 그대로 둔다)

역주는 짧게. 두 문장을 넘기면 해설로 옮긴다.

## 6. 원문 텍스트 다룰 때 주의

PDF에서 추출한 `.txt`에는 다음이 섞여 있다. 번역 전에 눈으로 걸러낸다.
- 페이지 머리말/꼬리말에 반복되는 책 제목·작가명·쪽번호
- 하이픈으로 행이 갈린 단어(`under-\nstand`)
- 타이포그래픽 인용부호(`“ ” ‘ ’`)와 ASCII 인용부호의 혼재
- 챕터 첫 페이지의 제목·작가명 두 줄 — `verify.py`는 이 두 줄을 제외하고 단어 수를 센다

## 7. 작업 순서 규율

- **한 편 = 한 파일 = 한 세션 단위.** 여러 편을 동시에 벌여놓지 않는다.
- 번역문을 스크립트 문자열로 조립하지 않는다. Read로 원문을 읽고 Write/append로 마크다운을 직접 쓴다.
- 긴 작품을 나눠 쓸 때는 **원문 문단 경계**에서만 끊고, 끊은 지점의 원문 마지막 문장을 기록해둔다.
- 한 편이 끝나면 즉시 `verify.py`. 비율 2.0 미만이면 다음 편으로 넘어가지 않는다.
