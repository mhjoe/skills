# 파일 규약 및 템플릿

## 파일명

```
NN_English_Title_한국어제목.md
```

- `NN` = 원전 수록 순서 2자리. 서문·머리말이 있으면 `00`
- 영문 제목의 아포스트로피·마침표·쉼표는 제거하거나 `_`로 치환
  - `Parson's Pleasure` → `Parsons_Pleasure`
  - `W. S.` → `W_S_`
- 공백은 `_`. 한국어 제목의 공백도 `_`
- 예: `08_Ringing_the_Changes_종을_울려_바꾸다.md`

## 작품 파일 템플릿

모든 작품 파일이 예외 없이 이 구조를 따른다. 섹션 순서와 이모지까지 고정 — `verify.py`가 `## 📖` 와 `## 🔍` 사이를 본문으로 잘라내 검증하기 때문이다.

```markdown
# NN. 한국어제목 (English Title)

> **원제**: *English Title*
> **작가**: 한국어 이름 (Original Name, 1920–1988)
> **최초 발표**: 1958년 3월, *잡지명*
> **수록**: *원전 제목* (출판사, 연도), pp. 66–68
> **분량**: 원문 약 960 단어 — (특징이 있으면 여기 한마디)
> **특기사항**: (엮은이가 서문에서 언급했다면 그 인용, 작가의 다른 수록작과의 관계, 작품사적 위치)
> **등장인물**:
> - **화자**: 쉰 살에 가까운 독신 여교사. …
> - **프랜시스 랜델 (Francis Randel)**: 스무 살의 청년 시인. …

---

## 📖 본문 완역 (Full Unabridged Translation)

### 한국어제목 — 작가 이름

(전편 번역. 생략·요약 금지.)

---

## 🔍 작품 심층 해설 및 감상 포인트

### 1. 소제목
- 내용

### 2. 소제목
- 내용
```

서지 블록의 각 줄 끝에는 마크다운 줄바꿈용 **공백 두 칸**을 넣는다.

## 서지 블록 작성 요령

- **분량** 줄에는 `verify.py`가 계산한 원문 단어 수를 그대로 적는다. 나중에 README 목차표를 쓸 때 여기서 긁어온다.
- **특기사항**은 비워두지 말 것. 쓸 게 없으면 그 작품이 선집 안에서 차지하는 위치(최장/최단/최고(最古)/유일한 1인칭 등)라도 적는다.
- **등장인물**은 이름 + 나이·직업 + 외양 + 서사적 기능 순으로 한두 문장. 결말 스포일러는 여기 쓰지 않는다(해설로 미룬다).

## 🔍 심층 해설 작성 요령

번역과 같은 비중으로 공을 들이는 부분이다. **5~7개 항목**, 각 항목은 번호 + 소제목 + 불릿.

항목으로 자주 쓰이는 각(角):
1. **구조** — 이 작품이 뒤집는 것 / 회전의 지점. (예: "1,000단어로 완성한 완벽한 회전")
2. **복선** — 다시 읽으면 도입부에 이미 답이 적혀 있다는 식으로, 본문에서 실제 문장을 인용해 짚는다
3. **징후의 배치** — 작가가 단서를 어느 인물·어느 사물에 심었는지 목록으로
4. **기법** — 우연을 가장한 운명, 사무적 문서로 처리한 결말, 시점의 제한 등
5. **결말의 정확한 잔혹함** — 마지막 두세 줄이 왜 서늘한지 논리를 풀어 쓴다
6. **다른 작품과의 대구** — 같은 작가의 다른 수록작, 또는 앞뒤 편과 나란히 놓고 비교
7. **원문에서만 보이는 것** — 역주로 처리한 언어유희를 여기서 한 번 더 정리

작성 규칙:
- 해설 안에서 **번역문을 직접 인용**하고 `**굵게**` 처리한다. 인상비평이 아니라 텍스트에 붙은 분석이어야 한다.
- 줄거리 요약을 하지 않는다. 독자는 방금 본문을 읽었다.
- 근거 없는 전기적 추측(작가의 개인사 때문에 …)은 쓰지 않는다.

## README.md 색인 템플릿

번역 폴더 루트에 둔다. 전편이 완역 판정을 받은 뒤에 쓴다.

```markdown
# 👻 한국어 제목 한글 완역본 (English Title)

> **엮은이/지은이**: 이름 (Name, 1916 ~ 1990)
> **원전**: *Title*, City: Publisher, Year (ISBN13 …)
> **원본 초판**: *Original Title* (Publisher, Year)
> **총 분량**: 서문 1편 + 소설 14편 완결 (원문 약 80,563 단어 전편 완역)
> **번역 형식**: 작품별 독립 마크다운(`.md`) 파일 완역 + 작품별 서지 정보 & 등장인물 & 심층 해설
```
